# Python Basics: Strings

## String Creation

A **string** is a sequence of characters, created using single, double, or triple quotes.

```python
name = 'Mehedi'
city = "Dhaka"
bio = """Backend developer
based in Dhaka."""
```

- Single and double quotes work the same way — pick one and stay consistent
- Triple quotes (`'''` or `"""`) allow multi-line strings
- Use double quotes when the string itself contains a single quote, and vice versa

```python
quote = "It's a good day"
```

Strings can also be created using `str()`:

```python
str(100)     # "100"
str(True)    # "True"
```

---

## Indexing

Accessing a single character in a string by its position. Indexing starts at `0`.

```python
name = "Mehedi"

name[0]    # 'M'
name[1]    # 'e'
name[-1]   # 'i'  (last character)
name[-2]   # 'd'  (second to last)
```

- Positive indices count from the start (0, 1, 2, ...)
- Negative indices count from the end (-1, -2, ...)
- Accessing an index out of range raises an `IndexError`

---

## Slicing

Extracting a portion (substring) of a string using `start:stop:step`.

```python
name = "Mehedi Hasan"

name[0:6]     # 'Mehedi'
name[7:]      # 'Hasan'  (to the end)
name[:6]      # 'Mehedi' (from the start)
name[:]       # full copy of the string
name[::2]     # every second character
name[::-1]    # reversed string
```

- `start` is included, `stop` is excluded
- Omitting `start` defaults to the beginning; omitting `stop` defaults to the end
- `step` controls the interval, and can be negative to go backward

---

## String Immutability

Strings in Python **cannot be changed** after creation. Any operation that looks like it modifies a string actually returns a new one.

```python
name = "Mehedi"
name[0] = "T"   # raises TypeError
```

```python
name = "Mehedi"
new_name = "T" + name[1:]   # 'Tehedi' — a new string
```

Methods like `.upper()` or `.replace()` don't modify the original string — they return a new one:

```python
name = "mehedi"
name.upper()
print(name)   # still 'mehedi' — unchanged
```

## Common String Methods

Some frequently used built-in string methods:

| Method            | Description                          | Example                          |
|--------------------|----------------------------------------|-----------------------------------|
| `.upper()`         | Converts to uppercase                | `"hi".upper()` → `'HI'`           |
| `.lower()`         | Converts to lowercase                | `"HI".lower()` → `'hi'`           |
| `.strip()`         | Removes leading/trailing whitespace  | `" hi ".strip()` → `'hi'`         |
| `.replace(a, b)`   | Replaces all `a` with `b`            | `"hi".replace("h","H")` → `'Hi'`  |
| `.title()`         | Capitalizes each word                | `"john doe".title()` → `'John Doe'` |
| `.capitalize()`    | Capitalizes only the first character | `"hello".capitalize()` → `'Hello'` |
| `.count(sub)`      | Counts occurrences of a substring    | `"aaa".count("a")` → `3`          |

```python
text = "  Hello World  "
text.strip().lower()   # 'hello world'
```

## Searching

Checking whether a substring exists, and where.

```python
name = "Mehedi Hasan"

"Hasan" in name          # True
name.find("Hasan")       # 7  (index where it starts)
name.find("xyz")         # -1 (not found)
name.index("Hasan")      # 7  (like find, but raises ValueError if not found)
name.startswith("Me")    # True
name.endswith("san")     # True
```

- `in` is the simplest way to check for existence — returns a `bool`
- `.find()` returns `-1` if not found; `.index()` raises an error instead

---

## split()

Splits a string into a list of substrings, based on a separator.

```python
"a,b,c".split(",")          # ['a', 'b', 'c']
"hello world".split()       # ['hello', 'world']  (splits on whitespace by default)
"a-b-c".split("-", 1)       # ['a', 'b-c']  (maxsplit limits number of splits)
```

Useful for parsing structured text like CSV lines or sentences.

---

## join()

The reverse of `split()` — joins a list of strings into a single string, using a separator.

```python
words = ["Mehedi", "is", "learning", "Python"]
" ".join(words)      # 'Mehedi is learning Python'

",".join(["a", "b", "c"])   # 'a,b,c'
```

`join()` is called on the separator string, and takes an iterable of strings as its argument.

## String Formatting

Ways to build strings that include variable values.

### % formatting (old style)

```python
name = "Mehedi"
"Hello, %s" % name
```

### .format()

```python
"Hello, {}".format(name)
"Hello, {0}! You are {1}.".format(name, 25)
```

### f-strings (modern, preferred — see below)

```python
f"Hello, {name}"
```

---

## f-strings

Formatted string literals — the modern, preferred way to embed expressions inside strings, prefixed with `f`.

```python
name = "Mehedi"
age = 25

print(f"Hello, {name}. You are {age} years old.")
```

Expressions inside `{}` are evaluated directly:

```python
price = 100
tax = 0.15
print(f"Total: {price * (1 + tax)}")
```

Formatting numbers with f-strings:

```python
pi = 3.14159
print(f"{pi:.2f}")   # '3.14'
```

f-strings are generally faster and more readable than `%` or `.format()`.

## Escape Sequences

Special character combinations, starting with a backslash `\`, used to represent characters that are otherwise hard to type directly.

| Sequence | Meaning         |
|----------|------------------|
| `\n`     | New line          |
| `\t`     | Tab               |
| `\\`     | Backslash         |
| `\'`     | Single quote      |
| `\"`     | Double quote      |
| `\r`     | Carriage return   |

```python
print("Line1\nLine2")
print("Name:\tMehedi")
print("She said \"hello\"")
```

To ignore escape sequences entirely, use a raw string with the `r` prefix:

```python
path = r"C:\Users\Mehedi"
```

## Unicode Basics

Python 3 strings are Unicode by default — they can represent characters from virtually any language or symbol set.

```python
text = "বাংলা"
symbol = "π"
print(text, symbol)
```

- `len()` counts Unicode characters, not raw bytes
- `ord(char)` gives a character's Unicode code point; `chr(code)` does the reverse

```python
ord("A")      # 65
chr(65)       # 'A'
```

When strings need to be stored or sent as raw bytes (e.g. over a network or to a file), they're encoded, typically as UTF-8:

```python
"হ্যালো".encode("utf-8")
```

## Key Points

- Strings can be created with single, double, or triple quotes; triple quotes allow multi-line text
- Indexing accesses one character by position; slicing extracts a substring with `start:stop:step`
- Strings are immutable — every "modification" returns a new string
- Common methods include `.upper()`, `.lower()`, `.strip()`, `.replace()`, `.title()`
- `in`, `.find()`, `.index()`, `.startswith()`, `.endswith()` are used to search within strings
- `split()` breaks a string into a list; `join()` combines a list back into a string
- f-strings (`f"{value}"`) are the preferred way to format strings, over `%` and `.format()`
- Escape sequences (`\n`, `\t`, etc.) represent special characters; `r"..."` disables them
- Python 3 strings are Unicode by default; `ord()` / `chr()` convert between characters and code points
