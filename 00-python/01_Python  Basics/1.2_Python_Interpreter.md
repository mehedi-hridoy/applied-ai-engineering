# Python Interpreter

Before understanding the Python interpreter, first understand the difference between **compiled** and **interpreted** languages.

## Compiled vs Interpreted Languages

### Compiled Language

In a traditional compiled language, source code is converted into **machine code before execution**.

```text
Source Code
     ↓
Compiler
     ↓
Machine Code
     ↓
CPU
     ↓
Program Runs
```

Examples:

- C
- C++
- Rust

The compiler translates the program into instructions that the CPU can directly execute.

---

### Interpreted Language

In an interpreted model, a runtime program reads and executes the code instead of producing a standalone machine-code executable first.

```text
Source Code
     ↓
Interpreter
     ↓
Execution
     ↓
Result
```

However, **Python is not simply "read line by line and executed."** Modern Python implementations such as CPython first compile Python source into **bytecode**, then execute that bytecode.

---

## What is a Python Interpreter?

A **Python interpreter** is the program or runtime responsible for processing and executing Python code.

For the standard implementation, **CPython**, the process is roughly:

```text
Python Source Code
       ↓
   Tokenization
       ↓
    Parsing / AST
       ↓
Bytecode Compilation
       ↓
     Bytecode
       ↓
Python Virtual Machine
       ↓
    Execution
```

The interpreter/runtime is responsible for things such as:

- Detecting syntax errors
- Compiling Python source into bytecode
- Managing Python objects and execution
- Executing bytecode
- Producing the program's result

---

## How Python Code Runs

Consider this example:

```python
x = 5 + 3
print(x)
```

### 1. Source Code

You write Python code in a `.py` file:

```text
program.py
```

---

### 2. Tokenization and Parsing

Python analyzes the source code and breaks it into tokens.

It then parses those tokens and creates an **AST (Abstract Syntax Tree)** that represents the program's structure.

```text
Source Code
     ↓
Tokens
     ↓
AST
```

---

### 3. Bytecode Compilation

The Python implementation compiles the program into **bytecode**.

Bytecode is an intermediate representation of the program.

```text
AST
 ↓
Bytecode
```

Python may cache compiled bytecode in:

```text
__pycache__/
```

as `.pyc` files.

> `.pyc` contains bytecode, not CPU machine code.

---

### 4. Python Virtual Machine

The **Python Virtual Machine (PVM)** executes the bytecode.

Conceptually:

```text
Bytecode
   ↓
PVM
   ↓
Execution
```

For example:

```python
x = 5 + 3
```

The bytecode execution ultimately produces:

```text
x = 8
```

---

### 5. Result

The executed program produces its result.

For:

```python
print(x)
```

The output is:

```text
8
```

---

## Interpreter vs PVM

These terms are related but **not exactly the same thing**.

### Python Interpreter / Runtime

This is the broader program responsible for processing and running Python programs.

### Python Virtual Machine (PVM)

This is the component that executes the compiled **Python bytecode**.

Think of it like this:

```text
Python Interpreter / Runtime
          │
          ├── Tokenization
          ├── Parsing
          ├── Compilation
          │
          └── PVM
                ↓
           Executes Bytecode
```

---

## Important: Python is Not Simply "Line by Line"

A common beginner explanation says:

> "Python executes code line by line."

This is useful as a rough introduction, but it is **not technically accurate**.

A better mental model is:

```text
.py source
    ↓
Tokenization / Parsing
    ↓
Bytecode
    ↓
PVM
    ↓
Execution
```

Python can execute code sequentially, but it does **not** simply take one source-code line, translate it directly into machine code, execute it, and then move to the next line.

---

## CPython

**CPython** is the standard and most widely used implementation of Python.

It is written primarily in **C**.

When most people install Python from the official Python distribution and run:

```bash
python program.py
```

They are typically using **CPython**.

Other Python implementations also exist, such as:

- PyPy
- Jython
- IronPython

They can use different execution techniques while still implementing the Python language.

---

## Key Takeaways

- A **Python interpreter** runs Python code.
- Python source is first parsed and compiled into **bytecode**.
- The **PVM** executes the bytecode.
- **CPython** is the standard Python implementation.
- Python is more than just direct line-by-line execution; it involves compilation and runtime execution steps.
