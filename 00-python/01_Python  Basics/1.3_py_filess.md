# `.py` File

A **`.py` file** is a file that contains **Python source code**.

Example:

```python
# hello.py

name = "Mehedi"
print(name)
```

The `.py` extension tells us that the file contains Python code.

## Python Executable

The program that reads and executes Python code is the **Python interpreter**.

The standard Python implementation is **CPython**.

Python is commonly started using:

```bash
python
```

On Windows, you can also use:

```bash
py
```

On Linux/macOS:

```bash
python3
```

---

## Two Ways to Use Python

Python can be used mainly in two ways:

```text
Python
├── Interactive Mode (REPL)
└── File Execution Mode
```

### 1. Interactive Mode (REPL)

Start Python:

```bash
python
```

You will see:

```text
>>>
```

This is the Python interactive shell.

You can immediately execute code:

```python
>>> 1 + 2
3

>>> 2 + 3 * 4
14
```

The `>>>` prompt means Python is waiting for your input.

---

### 2. File Execution Mode

Instead of entering code line by line, save the code inside a `.py` file.

Example:

```text
hello.py
```

```python
print(1 + 2)

price = 23.45
tax_rate = 0.20

tax = price * tax_rate
total_price = price + tax

print(tax)
print(total_price)
```

Run it using:

```bash
python hello.py
```

On Windows:

```bash
py hello.py
```

---

## REPL vs `.py` File

| REPL                 | `.py` File        |
| -------------------- | ----------------- |
| Interactive          | Saved source code |
| Uses `>>>`           | No `>>>`          |
| Executes immediately | Run when needed   |
| Good for experiments | Good for programs |

---

## `.py` File Execution Flow

```text
.py Source Code
      ↓
Python Interpreter
      ↓
Tokenization / Parsing
      ↓
Bytecode
      ↓
PVM
      ↓
Execution
      ↓
Output
```

## Important

In the REPL:

```python
>>> 1 + 2
3
```

Python automatically displays the result.

In a `.py` file:

```python
1 + 2
```

The result is not normally displayed.

Use:

```python
print(1 + 2)
```

to display it.

---

## `.py` vs `.pyc`

```text
.py
 ↓
Python source code
```

```text
.pyc
 ↓
Python bytecode
```

Python may store cached `.pyc` files inside:

```text
__pycache__/
```

You normally write and edit `.py` files, not `.pyc` files.

---

## Key Points

- `.py` = **Python source-code file**
- Python code is written inside `.py` files.
- `python file.py` executes a Python file.
- `>>>` indicates the Python **REPL**.
- REPL is useful for quick experimentation.
- `.py` files are used to save and build programs.
- `.py` contains source code.
- `.pyc` contains compiled Python bytecode.
- `__pycache__` commonly stores `.pyc` files.
