# The `.py` File

A **`.py` file** is a file that contains **Python source code**.

### Example

```python
# hello.py

name = "Mehedi"
print(name)
```

The `.py` extension tells Python (and your editor) that the file contains Python code.

---

## The Python Executable

The program that reads and executes Python code is the **Python interpreter**.

The standard, most widely used implementation is **CPython**.

Python is commonly started using one of the following commands:

| Platform      | Command   |
|---------------|-----------|
| Windows       | `python` or `py` |
| Linux / macOS | `python3` |

---

## Two Ways to Use Python

```text
Python
├── Interactive Mode (REPL)
└── File Execution Mode
```

### 1. Interactive Mode (REPL)

Start Python:

```bash
python
```

You'll see the prompt:

```text
>>>
```

This is the **Python interactive shell** (REPL — Read, Eval, Print, Loop).

You can execute code immediately:

```python
>>> 1 + 2
3

>>> 2 + 3 * 4
14
```

The `>>>` prompt means Python is waiting for your input.

---

### 2. File Execution Mode

Instead of typing code line by line, save it inside a `.py` file.

**`hello.py`**
```python
print(1 + 2)

price = 23.45
tax_rate = 0.20

tax = price * tax_rate
total_price = price + tax

print(tax)
print(total_price)
```

Run it with:

```bash
python hello.py
```

On Windows:

```bash
py hello.py
```

---

## REPL vs `.py` File

| REPL                  | `.py` File          |
|-----------------------|----------------------|
| Interactive            | Saved source code    |
| Uses `>>>`              | No `>>>`              |
| Executes immediately   | Run when needed      |
| Good for experiments   | Good for programs    |

---

## `.py` File Execution Flow

```text
.py Source Code
      ↓
Python Interpreter
      ↓
Tokenization / Parsing
      ↓
Bytecode
      ↓
Python Virtual Machine (PVM)
      ↓
Execution
      ↓
Output
```

---

## Important: Auto-Display vs `print()`

In the **REPL**, results are shown automatically:

```python
>>> 1 + 2
3
```

In a **`.py` file**, the result is *not* displayed automatically:

```python
1 + 2   # nothing is printed
```

You must explicitly use `print()`:

```python
print(1 + 2)   # 3
```

---

## `.py` vs `.pyc`

```text
.py   →  Python source code
.pyc  →  Compiled Python bytecode
```

Python may cache compiled `.pyc` files inside a `__pycache__/` directory.

You normally write and edit `.py` files, not `.pyc` files directly.

---

## Key Points

- `.py` = **Python source-code file**
- Python code is written inside `.py` files
- `python file.py` executes a Python file
- `>>>` indicates the Python **REPL**
- REPL is useful for quick experimentation
- `.py` files are used to save and build programs
- `.py` contains source code
- `.pyc` contains compiled bytecode
- `__pycache__` commonly stores `.pyc` files
