# Python Basics: Operators

## Arithmetic Operators

Used to perform mathematical calculations.

| Operator | Meaning         | Example    | Result |
|----------|------------------|------------|--------|
| `+`      | Addition          | `5 + 2`    | `7`    |
| `-`      | Subtraction       | `5 - 2`    | `3`    |
| `*`      | Multiplication    | `5 * 2`    | `10`   |
| `/`      | Division          | `5 / 2`    | `2.5`  |
| `//`     | Floor division    | `5 // 2`   | `2`    |
| `%`      | Modulus (remainder) | `5 % 2`  | `1`    |
| `**`     | Exponentiation    | `5 ** 2`   | `25`   |

```python
price = 100
tax = price * 0.15
total = price + tax
```

Note that `/` always returns a `float`, even when the numbers divide evenly:

```python
10 / 2   # 5.0
```

`//` discards the remainder and returns the floor of the result:

```python
7 // 2    # 3
-7 // 2   # -4  (rounds toward negative infinity, not zero)
```

## Comparison Operators

Compare two values and return a `bool`.

| Operator | Meaning                  | Example   | Result |
|----------|---------------------------|-----------|--------|
| `==`     | Equal to                 | `5 == 5`  | `True` |
| `!=`     | Not equal to              | `5 != 3`  | `True` |
| `>`      | Greater than              | `5 > 3`   | `True` |
| `<`      | Less than                 | `5 < 3`   | `False`|
| `>=`     | Greater than or equal to  | `5 >= 5`  | `True` |
| `<=`     | Less than or equal to     | `5 <= 3`  | `False`|

```python
age = 20
print(age >= 18)   # True
```

`==` checks value equality, not identity — this differs from `is` (see Identity Operators below).

---

## Logical Operators

Combine or invert boolean expressions.

| Operator | Meaning                              | Example              |
|----------|----------------------------------------|-----------------------|
| `and`    | True if both conditions are true       | `x > 0 and x < 10`    |
| `or`     | True if at least one condition is true | `x < 0 or x > 100`    |
| `not`    | Inverts a boolean value                | `not is_active`       |

```python
age = 25
has_id = True

if age >= 18 and has_id:
    print("Allowed entry")
```

Python evaluates these with short-circuiting: in `a and b`, `b` is only evaluated if `a` is truthy; in `a or b`, `b` is only evaluated if `a` is falsy.

## Assignment Operators

Assign a value to a variable, optionally combined with an operation.

| Operator | Equivalent to     | Example    |
|----------|--------------------|------------|
| `=`      | `x = value`        | `x = 5`    |
| `+=`     | `x = x + value`    | `x += 3`   |
| `-=`     | `x = x - value`    | `x -= 3`   |
| `*=`     | `x = x * value`    | `x *= 3`   |
| `/=`     | `x = x / value`    | `x /= 3`   |
| `//=`    | `x = x // value`   | `x //= 3`  |
| `%=`     | `x = x % value`    | `x %= 3`   |
| `**=`    | `x = x ** value`   | `x **= 3`  |

```python
total = 100
total += 50   # total is now 150
total *= 2    # total is now 300
```

## Identity Operators

Check whether two variables refer to the same object in memory — not just equal values.

| Operator | Meaning                          |
|----------|------------------------------------|
| `is`     | True if same object               |
| `is not` | True if not the same object       |

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)   # True  (same values)
print(a is b)   # False (different objects in memory)
print(a is c)   # True  (c points to the same object as a)
```

A common use is checking against `None`:

```python
value = None
if value is None:
    print("No value set")
```

`is` should be used for singleton checks like `None`, `True`, `False` — not for general value comparison.

---

## Membership Operators

Check whether a value exists within a sequence (string, list, tuple, set, dict).

| Operator  | Meaning                            |
|-----------|--------------------------------------|
| `in`      | True if value is present            |
| `not in`  | True if value is not present        |

```python
fruits = ["apple", "banana", "mango"]

print("banana" in fruits)       # True
print("grape" not in fruits)    # True

name = "Mehedi"
print("M" in name)              # True
```

For a `dict`, `in` checks against the keys by default:

```python
user = {"name": "Mehedi", "age": 25}
print("name" in user)   # True
```

---

## Key Points

- Arithmetic operators (`+ - * / // % **`) perform numeric calculations; `/` always returns a `float`, `//` floors the result
- Comparison operators (`== != > < >= <=`) return a `bool`
- Logical operators (`and or not`) combine boolean expressions and short-circuit evaluation
- Assignment operators (`= += -= *= ...`) assign and update variables in one step
- Identity operators (`is`, `is not`) compare object identity, not value equality — mainly used with `None`
- Membership operators (`in`, `not in`) check whether a value exists inside a sequence
