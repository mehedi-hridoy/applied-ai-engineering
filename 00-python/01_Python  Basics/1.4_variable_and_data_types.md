## Variables

A **variable** is a name that refers to a value stored in memory.

```python
name = "Mehedi"
age = 25
```

- `=` is the assignment operator, not "equals" in the mathematical sense.
- A variable is created the moment you first assign a value to it.
- Variables can be reassigned to a different value, even of a different type.

```python
x = 10
x = "now a string"
```

---

## Naming Conventions

Rules (must follow):

- Names can contain letters, digits, and underscores (`_`)
- Names cannot start with a digit
- Names are case-sensitive (`age` and `Age` are different)
- Cannot use Python reserved keywords (`if`, `for`, `class`, etc.)

Conventions (should follow):

- Use `snake_case` for variables and functions: `total_price`, `user_name`
- Use `UPPER_CASE` for constants: `MAX_SIZE = 100`
- Use `PascalCase` for class names: `class UserAccount:`
- Choose descriptive names over short, unclear ones

```python
# good
tax_rate = 0.15

# avoid
tr = 0.15
```

---

## Dynamic Typing

Python is **dynamically typed**: you don't declare a variable's type, and a variable can be reassigned to a value of a different type at any point.

```python
value = 10        # int
value = "ten"     # now str
value = 10.0      # now float
```

The type is determined at runtime, based on the value currently assigned — the type belongs to the value, not the variable name.

## Primitive Data Types

Python's built-in basic (scalar) data types:

| Type    | Description                  | Example         |
|---------|-------------------------------|------------------|
| `int`   | Whole numbers                 | `42`             |
| `float` | Decimal numbers                | `3.14`           |
| `bool`  | Boolean value                 | `True`, `False`  |
| `str`   | Text                           | `"hello"`        |
| `None`  | Represents "no value"         | `None`           |

### int

Whole numbers, positive or negative, with no size limit (beyond available memory).

```python
count = 10
temperature = -5
```

### float

Numbers with a decimal point, or numbers using scientific notation.

```python
price = 23.45
pi = 3.14159
scientific = 1.5e3   # 1500.0
```

### bool

Represents one of two values: `True` or `False`. Used for logical conditions.

```python
is_active = True
is_admin = False
```

Internally, `bool` is a subtype of `int` — `True` behaves as `1`, `False` as `0`.

### str

A sequence of characters, enclosed in single, double, or triple quotes.

```python
name = "Mehedi"
message = 'Hello'
paragraph = """Multiple
lines"""
```

### None

Represents the absence of a value. It is Python's version of "nothing" or "null".

```python
result = None
```

`None` is commonly used as a default or placeholder value before something meaningful is assigned.

## Type Conversion

Converting a value from one type to another, either automatically or manually.

### Implicit Conversion (done by Python)

```python
result = 5 + 2.0   # int + float -> 8.0 (float)
```

### Explicit Conversion (done by you)

```python
int("10")        # 10
float("3.14")     # 3.14
str(100)          # "100"
bool(0)           # False
bool(1)           # True
```

Not every conversion is valid:

```python
int("abc")   # raises ValueError
```

## type()

Returns the type of a value or variable.

```python
type(10)          # <class 'int'>
type(3.14)        # <class 'float'>
type("hello")     # <class 'str'>
type(True)        # <class 'bool'>
type(None)        # <class 'NoneType'>
```

Useful for checking exactly what type a value is at runtime.

---

## isinstance()

Checks whether a value is an instance of a given type. Returns `True` or `False`.

```python
isinstance(10, int)         # True
isinstance(10, float)        # False
isinstance("hi", str)        # True
isinstance(True, int)        # True (bool is a subclass of int)
```

`isinstance()` is generally preferred over `type()` for type checks, since it also accounts for inheritance.

## Input / Output

### Output — `print()`

Displays information to the console.

```python
print("Hello, world!")
print("Age:", 25)
```

### Input — `input()`

Reads a line of text typed by the user. Always returns a `str`.

```python
name = input("Enter your name: ")
print("Hello,", name)
```

Since `input()` always returns a string, convert it if you need a number:

```python
age = int(input("Enter your age: "))
```

---

## Key Points

- Variables are names bound to values; Python figures out the type automatically
- Follow `snake_case` for variables, `UPPER_CASE` for constants, `PascalCase` for classes
- Python is dynamically typed — a variable's type can change as it's reassigned
- Core primitive types: `int`, `float`, `bool`, `str`, `None`
- Type conversion can happen implicitly or be done explicitly with `int()`, `float()`, `str()`, `bool()`
- `type()` returns the exact type of a value
- `isinstance()` checks type membership, including inherited types
- `print()` sends output to the console; `input()` reads user input as a string
